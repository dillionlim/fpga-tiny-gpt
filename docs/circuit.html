GreyBadge Tiny LLM

An 84K-parameter character-level GPT that runs entirely inside the badge's Lattice ECP5. The RP2350 loads the bitstream and passes text back and forth. Every multiply, attention score and sampled character is computed in FPGA fabric.

  • FPGALFE5U-25F
  • clock31 MHz
  • block RAM48 / 56
  • logic21%
  • DSP3 / 28
  • per char≈5.8 ms
